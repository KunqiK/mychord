# 扒谱工具 · 使用说明

## 🆕 拆乐器(像 LALAL.AI 那样,但免费本地)

把歌**拖到桌面的「拆乐器」图标上**,出 6 条轨的音频文件:

> 人声 / 鼓 / 贝斯 / **吉他** / **钢琴** / 其他

用的是 MVSEP 排行榜第一的模型 —— **钢琴和吉他的分离质量实测超过 LALAL.AI 和 Logic Pro**。

- ⏳ 这个模型比普通分离重得多:**纯 CPU 一首歌要跑几十分钟**(跑完永久缓存,同一首歌第二次秒开)。拖上去就去干别的,好了窗口会提示
- 出来的 stems 文件夹里是 .flac,直接拖进 FL Studio / NeuralNote
- 想要**更多乐器**(synth、弦乐、电吉他、木吉他、管风琴、萨克斯、小提琴、铜管…共 53 种),叫 Claude 帮你跑,或自己在命令行:
  ```
  "K:\Claude Projects\!!!ChordHUD\auto-transcribe\transcribe.cmd" "歌.flac" --stems synth,strings,eguitar --stems-only
  ```
  每个乐器是一个单独的小模型(首次自动下载 ~78MB),会同时给你「该乐器」和「伴奏减去该乐器」两条轨

## 第一步:扒谱(1 个动作)

把歌曲文件(flac / mp3 / wav)**用鼠标拖到桌面的「拖歌扒谱」图标上,松手**。

- 会弹出一个黑色窗口,自己跑,不用管
- 新歌第一次要 3~5 分钟(AI 在分离人声/鼓/贝斯);同一首歌再拖一次只要几秒
- 跑完**结果文件夹自动打开**

就这样。没有第二个动作。

---

## 第二步:结果文件夹里有什么

结果在 `K:\Claude Projects\!!!ChordHUD\auto-transcribe\output\<歌名>\`(会自动打开)。

### 🎧 preview.wav —— 先听这个

双击播放。这是**原曲 + 我扒出来的和弦垫**混在一起。

- 听着和谐 = 和弦扒对了
- 听着"打架"、别扭 = 那个地方和弦错了,记下时间点

这是最快判断质量的方法,不用看任何数据。

### 📄 report.md —— 扒谱报告

用记事本或 VSCode 打开。最上面是:

- 这首歌的调、BPM
- **「低置信度段」清单** = 我自己也不确定的地方,**按最可能错的排在最前**

修正的时候只看这张清单就够了,不用从头听到尾。

### 🎹 歌名.chordhud.json —— ChordHUD 工程

这是给 ChordHUD 用的。步骤:

1. 打开 `chord_hud_v17.4.html`(在 `K:\Claude Projects\!!!ChordHUD\` 里,双击就能用)
2. 点左上角 **📂 载入工程**
3. 选这个 `.json` 文件

整首歌的和弦、时间点、调、音级高亮**全部已经填好了**。每个和弦下面还有几个**备选和弦按钮**,觉得不对就点一下换掉。

对照 report.md 的清单,把标记的几段听一遍、点备选换掉,就完成了。

### 🎼 melody.mid —— 人声主旋律

拖进 FL Studio。已经对齐到 16 分音符网格了(按正常写谱的方式)。
- `melody_raw.mid` 是没量化的版本(保留演唱的实际位置),想自己修节奏时用这个

### 🎼 lines.mid —— 多轨旋律草稿

拖进 FL Studio 会看到 **3~4 条轨**:

| 轨 | 是什么 |
|---|---|
| Primary | 人声主旋律(同 melody.mid) |
| Lead candidate | 器乐主音的猜测线条 |
| Other stem (full poly draft) | **伴奏里所有能听出来的音符** —— 故意多扒,给你删的 |

**第三轨的用法**:音符的**力度(velocity)= 我的把握程度**。在钢琴卷帘里拉一条力度过滤线,力度低的先删掉,剩下的对着原曲 loop 听,留对的删错的。

Arp(琶音)特别划算:修对一小节,复制粘贴到整段。

### 🎹 piano.mid —— 钢琴专用引擎(可选)

只有加了 `--piano` 才有。用的是 ByteDance 的钢琴模型,**带力度和踏板**,对真钢琴录音效果很好,对电子合成音色一般。

## 常见需求

### 觉得节拍/小节线对不上

拖歌时用的是自动判断的强拍位置,可能差半拍。修法:开始菜单搜 `cmd` 打开命令提示符,粘贴这行(路径换成你的歌):

```
"K:\Claude Projects\!!!ChordHUD\auto-transcribe\transcribe.cmd" "歌曲完整路径.flac" --click --downbeat-shift 1
```

`--downbeat-shift` 后面的数字试 0/1/2/3。加了 `--click` 后 preview.wav 里会有节拍声(强拍是高音),一听就知道对不对。因为分离结果有缓存,重跑只要几秒。

### BPM 判错了

```
... transcribe.cmd "歌.flac" --bpm 150
```

### 想要钢琴引擎的 piano.mid

```
... transcribe.cmd "歌.flac" --piano
```
